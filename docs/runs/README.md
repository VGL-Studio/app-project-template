# PHIÊN TỰ CHẠY

Mỗi file `RUN-YYYYMMDD-NN.md` là danh sách chạy và báo cáo của một phiên tự chạy, theo [mẫu phiên tự chạy](../templates/run.md) và [quy trình](../auto-run.md).

Phiên của dự án mẫu được nhắc trong tài liệu (ADR, ticket, plan) mà không có file trong thư mục này thì đọc ở commit b24fbf4 (`git show b24fbf4:docs/runs/<tên file>`). Phiên mà `docs/lessons.md` ghi nguồn là một app (ví dụ camera-pose) nằm ở repo của app đó.
