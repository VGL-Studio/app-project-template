# BÁO CÁO PHIÊN THỬ TRÊN MÁY

Mỗi file `TS-YYYYMMDD-NN.md` là báo cáo AI phân tích một phiên thử bản staging trên máy thật, theo [mẫu phiên thử](../templates/test-session.md). Cách ghi phiên và nhờ AI phân tích: [docs/ops/test-sessions.md](../ops/test-sessions.md).

Log thô của phiên nằm ở `test-sessions/` tại gốc repo trên máy người thử, không vào git. Kết quả kịch bản trên emulator trước khi phát staging ghi trong báo cáo phiên tự chạy (`docs/runs/`), mục Kiểm thử trên máy ảo.
